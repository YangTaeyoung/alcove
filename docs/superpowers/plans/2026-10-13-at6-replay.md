# AT6 — replay: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A sequence of actions that an agent performed once can be saved as a script and replayed without a model, for regression runs.

**Architecture:** A script is a JSON file of control ops with variables and expectations. `ScriptRunner` in `AlcoveControl` executes it through `ControlHandler`. `ScriptBuilder` turns a recorded trace into a script, replacing refs and coordinates by selectors that the trace captured at record time. `alcovectl run-script` and two MCP tools expose it.

**Tech Stack:** Swift 6; C# 5 helper (one new op); TypeScript MCP server; Python 3 standard library for end-to-end scripts.

**Spec:** `docs/superpowers/specs/2026-10-13-ai-testing-tools-design.md`

## Global Constraints

- Script format version 1:
  ```json
  {"version": 1, "vm": "Windows 11", "variables": {"message": "hello"},
   "steps": [{"label": "type the message", "op": "vm.ui.type",
              "params": {"selector": {"role": "Edit", "name": "Message"}, "text": "${message}"},
              "expect": [{"type": "ui_exists", "role": "Button", "name": "Send"}],
              "timeout": 10}]}
  ```
- `${name}` is replaced inside string params and expectation fields; an undefined variable fails before any step runs (`variable '<name>' is not defined; pass it or add a default`).
- A step's `params` never contain `name` or `lease`; the runner adds the VM name and its own lease token.
- Step ops allowed: every control op except `vm.lease.*`, `vm.record.*`, `script.*`, `vm.clone`, `vm.delete`.
- `expect` holds wait conditions of `vm.wait_for`; every one must hold within the step's `timeout` (default 10 s).
- A `vm.wait_for` step fails the run when it ends with `matched == -1`.
- The runner stops at the first failing step.
- Error strings are plain sentences that name the next step.
- Comments, test names and test comments describe what the code does now. No history, rationale, measurements or review notes in code.
- Code, identifiers and repository docs are English.

## Review Focus

1. A malformed script (not JSON, wrong version, a step without `op`, a disallowed op): refused before any step runs, with the step index (Task 1 `testRejectsMalformedScripts`).
2. A selector that matches nothing at replay time: the step fails with the selector in the message and the run returns a screenshot of that moment (Task 1 `testFailureCarriesObservationImage`).
3. A trace with coordinate clicks on a spot that had no UI element (desktop, custom-drawn area): the saved step keeps coordinates (Task 2 `testCoordinateClickWithoutTargetKeepsCoordinates`).
4. Typed text containing `${` literally: saved scripts escape it as `$${` and the runner restores it (Task 1 `testDollarEscaping`, Task 2 `testSavedTextIsEscaped`).
5. A VM that is leased by someone else when the run starts: the run fails at once with the lease owner (Task 1 `testRunFailsWhenLeasedByOther`).

### Task 1: Script model and runner

**Files:**
- Create: `AlcoveKit/Sources/AlcoveControl/Script.swift` (model, parsing, variable substitution), `ScriptRunner.swift`, `ControlHandler+Script.swift`, `AlcoveKit/Tests/AlcoveControlTests/ScriptTests.swift`
- Modify: `ControlHandler.swift` (dispatch `script.run`, `knownOps`)

**Interfaces:**
- Produces:
  ```swift
  struct Script: Sendable, Equatable {
      struct Step: Sendable, Equatable { var label: String?; var op: String; var params: [String: JSON]; var expect: [JSON]; var timeout: Int }
      var vm: String?; var variables: [String: String]; var steps: [Step]
      static func parse(_ data: Data) throws -> Script          // ScriptError with a step index where it applies
      func resolved(with overrides: [String: String]) throws -> Script
      func encoded() throws -> Data                              // pretty-printed, sorted keys
      static func escape(_ literal: String) -> String            // `${` becomes `$${`
  }
  struct ScriptResult: Sendable { var passed: Bool; var stepsRun: Int; var failedStep: Int?; var error: String?; var stepResults: [JSON]; var seconds: Double; var failureImage: Data? }
  struct ScriptRunner {
      init(handler: ControlHandler)
      func run(_ script: Script, vm: String?, variables: [String: String], progress: (@Sendable (Int, Script.Step, Result<JSON, Error>) -> Void)?) async -> ScriptResult
  }
  ```
- Control op `script.run`: `path` (script file on the host), `name?` (overrides the script's `vm`), `variables?` (object), `snapshot?` (restore this snapshot first) → `{passed, stepsRun, steps, failedStep?, label?, error?, seconds, failure?: {png (base64), width, height}}`. The runner acquires a lease for the run (owner `script:<file name>`, TTL 600 s renewed every 200 s) and releases it at the end.

### Task 2: Saving a script from a trace

**Files:**
- Modify: `guest-tools/internal/uia/assets/helper.cs` (`ui.at`), `guest-tools/internal/server/rpc.go` (register it), `scripts/test/uia-helper-check.py` (one check)
- Modify: `AlcoveKit/Sources/AlcoveControl/Recording.swift` and `ControlHandler+Record.swift` (trace lines of coordinate clicks gain `target`; UI ops gain `selector`)
- Create: `AlcoveKit/Sources/AlcoveControl/ScriptBuilder.swift`, `AlcoveKit/Tests/AlcoveControlTests/ScriptBuilderTests.swift`
- Modify: `ControlHandler+Script.swift` (`script.save`)

**Interfaces:**
- Helper op `ui.at`: `x`, `y` → `{node, window}` for the deepest element at that point, or `ok:false` with `no element at (x, y)`.
- While a recording is active: before `vm.mouse.click` and `vm.mouse.drag` the handler asks `ui.at` for the press point (300 ms budget; failures are ignored) and writes `target: {window (title), role, name, aid}` into the trace line; `vm.ui.*` lines carry `selector` built the same way from the result's `node` when the caller used a ref.
- Produces:
  ```swift
  enum ScriptBuilder {
      /// Steps from trace entries `from...to` (inclusive `seq`, defaults: all).
      static func build(trace: [JSON], vm: String, from: Int?, to: Int?) -> Script
  }
  ```
  Rules: only successful entries; read-only ops are dropped except `vm.wait_for` and `vm.wait_idle`; a click with a `target` that has a name or an automation id becomes `vm.ui.click` with that selector plus `fallback: {x, y}` in params (the runner clicks the coordinates when the selector finds nothing and notes `usedFallback` in the step result — add this to `ScriptRunner`); `vm.ui.*` entries use `selector` in place of `ref`; consecutive `vm.type` entries merge; typed text is escaped with `Script.escape`; each step's label is `<op> <short target>`; a step whose trace line shows a foreground window different from the previous one gains `expect: [{"type": "window_title", "contains": <title>}]`.
- Control op `script.save`: `dir` (recording directory) or `trace` (file), `path` (output), `name?`, `from?`, `to?` → `{path, steps}`.
