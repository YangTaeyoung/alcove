## Deviations

- The supplement expected error files for the guest steps when the agent is
  stopped. When the agent process ends, the server sees the tools disconnect
  and the collector skips the guest steps with one summary line, as
  documented; error files for every guest step appear only when the agent
  stays connected and does not answer (measured by suspending it).
- With the Hang window in front the UI helper is not busy (see the table), so
  "the two helper files carry their sentences" holds as: `windows.json` lists
  the window as not responding, `ui-tree.error.txt` holds the helper's
  sentence. The busy-helper sentence was produced by holding the helper with
  another client's call.
- Check 4 passes a second log file (`utf16.log`) besides `fixture.log`, and
  checks 4, 5 and 10 hold the extra checks of the supplement; checks 7 to 11
  are the supplement's.
- The brief's check 1 asks for a video of at least 2 s; the script also asks
  that every frame decodes. The frame read when a recording stops closes the
  video and gets no display time of its own (it is marked to be discarded,
  `ffprobe` flag `D`), so the last decoded frame lies up to 2 s (a still
  screen) before the video's end; the check allows 2.5 s.

## Not verified

- A server process without a window server session (no SSH key login to this
  host was set up).
- Linux guests (journal recipe, the bundle's Linux path).
- A full dump in a bundle; a dump larger than the 500 MiB budget.
- A guest whose system language has no English message table (the "still
  being written" sentence reads the agent's English error text).
- `vm.record.stop` issued while a collection copies the video; a recording
  that ends during that copy.
- The rendered event log recipe at medium integrity end to end (only its
  read and `-ListLog` calls were run there).
