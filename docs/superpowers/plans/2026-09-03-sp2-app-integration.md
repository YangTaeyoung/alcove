# SP2 — App integration of the guest agent

Status of the pieces (2026-09-03): the Go agent works inside Windows 11 and
Ubuntu (`scripts/test/agent-*.py`), and `AlcoveAgent.AgentClient` talks to it
from Swift with tests. What remains is wiring both into the engine and the app.

## Engine (AlcoveEngine)

- `VMConfig.agentToken: String` (UUID, generated at creation; `decode()` adds
  one to older configs) and `VMConfig.agentHostPort: Int` (chosen at creation
  from 17000...17999 by hashing the token; collisions are detected at start by
  trying to bind the port and picking the next free one, persisting the change).
- `QEMUCommandBuilder`: `-smbios type=11,value=alcove-token=<token>` and an
  extra `hostfwd=tcp:127.0.0.1:<agentHostPort>-:7645` on the user netdev.
- `VMController`: after `.running`, start an `AgentSession` task that retries
  `AgentClient.connect(port:expectedToken:)` every 3 s until the guest boots
  the agent; expose `agent: AgentClient?` and an `agentConnected` flag through
  the state stream (`State.running` stays; add `var toolsConnected: Bool`).
- Installer helper: `VMController.installAgent(binaryURL:)` pushes the agent
  binary through an existing agent connection (upgrade path) — first-time
  install stays manual/ISO for now (an "Alcove Tools" ISO with the agent and
  `install.cmd`/`install.sh` is generated by `scripts/make-tools-iso.sh`).

## App

- `VMSession`: observe `agent` events; show a "Tools" indicator in the status
  bar (connected / not installed) and an "Install Alcove Tools…" action that
  mounts the tools ISO into the VM's CD-ROM (`changeMedium`) and shows the
  one-line instruction.
- Clipboard sync (`ClipboardSync` @MainActor): poll `NSPasteboard.general.changeCount`
  every 500 ms while the VM window is key; on change with a string, call
  `agent.setClipboard(text:)`; on `.clipboardChanged` write the string to the
  pasteboard and remember the change count to avoid echo. Text only in v1.
- Drag and drop: `DisplayNSView` registers for `.fileURL`; on drop call
  `agent.pushFile(url, to: .desktop)` for each file with a progress toast; when
  the agent is not connected, show "Install Alcove Tools to drop files".
- Resolution follow: keep sending `ui` on window resize; with viogpudo /
  virtio_gpu the guest follows (verified with `alcovectl run --resize`).
- Shared folders: Linux via virtio-9p (`-fsdev local,security_model=mapped-xattr`
  + `virtio-9p-pci`; the agent mounts with `mount -t 9p`); Windows via a WebDAV
  server in the app (`WebDAVServer` on 127.0.0.1, forwarded like the agent
  port; the agent runs `net use Z: http://10.0.2.2:<port>/`). Design detail
  and the WebDAV implementation are the next brainstorm.

## Tests

- Engine: golden test for the smbios/hostfwd arguments; `VMControllerTests`
  gains an agent test using the Linux image when present (skipped otherwise).
- App: unit tests for `ClipboardSync` echo suppression with a fake agent.
- E2E: `scripts/test/agent-windows.py` grows a clipboard-through-the-app check
  once the app exposes an AppleScript/URL hook for tests.
